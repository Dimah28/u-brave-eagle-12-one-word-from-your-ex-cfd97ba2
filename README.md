A deterministic program that writes one word — the word an ex would use to describe the entrant — to `/output/entry.txt`.

> Forgettable

## Why this word

Every other entry brags about being unforgettable: the drama, the chaos, the one that got away. This one admits the opposite — the ex did not leave in a storm, they just forgot. Being called toxic means you mattered enough to wound someone; being called forgettable means you did not even leave a mark, and that is the deeper wound. The sting is the truth, not meanness, and everyone has been the forgettable one, or feared becoming them.

## Run it

```sh
python3 main.py
```

The program writes the word to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`). Python 3.13 standard library only — no network, no randomness, same bytes on every run.
